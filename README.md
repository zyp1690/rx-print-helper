# 处方打印助手

> © 2026 **火舞狂沙** · 个人作品，仅供内部与同行参考

面向药店与基层医疗机构的处方录入、识别与打印工具。纯前端单文件应用，**无需安装、无需联网，数据全部保存在本地**。

## 特性

### 智能识别

粘贴整张处方文字或收银小票，自动提取药品与患者信息。已适配多种真实排版：

- **标准处方文本** —— `美林混悬液/布洛芬混悬液 2g 100ML/瓶 10ML 必要时 口服 17.85 1瓶 17.85`
- **POS 收银小票** —— 自动跳过列名、操作项、批号、追溯码、收银员等噪音行
- **表格式明细** —— 识别「序号 / 商品信息 / 批号 / 零售价 / 实价 / 小计 / 销售员」等多列表格
- **品名规格对照** —— 识别「品名 + 规格」两列排版
- **患者信息** —— 姓名、性别、年龄、电话、会员号、地址支持多层兜底识别

### 药品清单库

内置 4000+ 条药品数据（通用名 / 品牌别名 / 规格 / 厂家 / 剂型 / 单位），支持搜索式快速录入，可按名称、别名、助记码、厂家模糊匹配。

### 处方要素

医院名称、患者姓名、性别、年龄、科别、就诊卡号、病历号、患者地址、处方医师、日期、发药药房、病情及诊断。

### 诊断管理

诊断条目支持**拖动排序**、**双击就地改名**、批量添加。

「手动添加诊断」输入的内容会**自动存入常用诊断列表**，下次可直接下拉选用；多个诊断之间用顿号「、」分隔（旧的逗号格式仍能正常读取）。

### 快速录入默认值

新建药品行已预填常用值，少打字：

| 字段 | 默认值 |
|---|---|
| 科别 | 普通内科 |
| 剂量单位 | 片 |
| 频次 | 每日一次 |
| 用法 | 口服 |
| 数量单位 | 盒 |

点「清空」也会重置回这些默认值。历史处方若字段为空或带旧版「皮试」标记，打开时自动补齐/清理。

### 医院名称记忆

填过一次就会记住，医院输入框变成**可下拉选择**，**最近用过的排在最前**，自动去重、最多保存 20 条。点「清空」不会清掉这份历史。

### 多联编辑

一张 A4 打印多张时，**每一联都是一份独立处方**：

- 侧栏顶部出现「正在录入 · 第1联 / 第2联 …」切换栏，点击可跳到任意一联
- 已录入的联带**绿色圆点**标记，空白联标「·空」
- 切换栏右侧 **「下一联 →」** 按钮：清空下一联并跳过去继续录，末联后回到第 1 联
- 正在编辑的那一联在预览中以**蓝色边框**高亮
- 医院、药房、医师、底部说明等抬头信息全联共享；患者与药品各联独立
- 空白联在预览中显示引导提示

### 下拉选项设置

顶栏 **「⚙ 设置」** 集中管理 6 组下拉候选——**科别 / 常用诊断 / 剂量单位 / 数量单位 / 用法 / 频次**。每组都支持：

- **拖动排序**（直接决定下拉菜单里的先后顺序）、**双击改名**、**删除**、回车**新增**
- **↑ 上移 / ↓ 下移**、**按拼音排序**、**恢复默认**

改动**立即生效并自动保存**，重启后仍在。

### 智能粘贴识别

支持**自然语言处方**、**POS 小票**、**药店清单**等多种格式，直接 Ctrl+V 粘贴即可：

- **处方文字** —— 识别药名、剂量、频次、用法、单价、数量，并对照内置药品库补全
- **Excel/表格清单** —— 从 Excel 直接复制过来的「名称 规格 单位 单价」固定列也能识别，自动判断末列数字是数量还是单价；药名尾部粘连的单位（如「消炎止咳片 盒」）会被剥离
- **竖排清单** —— 从 Excel **按行**复制（每种药占多行：名称/规格/厂家/单位/数量）同样支持，**带表头或无表头均可**，表头错别字（如「规怡」「生产正业」）也能识别；夹在中间的 `e.`、`#N/A` 等杂质行自动跳过
- **同名合并** —— 同一药品出现多次时**自动合并为一栏，数量累加**（如 3 + 3 + 2 → 8 盒），按药品库标准名判定，通用名与商品名混写也能合并
- **会员/患者信息** —— 小票上的姓名、性别、年龄、卡号可一并提取

> 顶栏「**清单示例**」按钮可载入一份表格清单演示效果。

### 打印排版

- **A4 拼版**：可选择**一张 A4 打印 1 / 2 / 4 张**处方。切换张数会**自动套用对应的方向组合**：

| 选择 | A4 纸张 | 处方内容 | 排布 | 缩放 |
|---|---|---|---|---|
| **1 张** | 横向 297×210 | **横向** 210×148 | 单张 | 100% |
| **2 张** | 横向 297×210 | **竖向** 148×210 | 并排 2 联 | 100%（原尺寸） |
| **4 张** | 横向 297×210 | **横向** 210×148 | 2×2 四联 | 约 70.7% |

> 「2 张」用竖向处方并排，恰好是原尺寸不缩小，打印后沿中线裁开即为两张标准竖式处方。
> 「4 张」横向内容 2×2 排布，格子 148.5×105mm，字号约七成，打印后裁成四联处方纸。

**两个方向可独立调整**：预览栏有「A4 纸张」（横/纵，仅拼版时显示）和「内容」（横/竖）两个控件，互不影响。

**实际输出纸张**

| 设置 | 打印纸张 |
|---|---|
| 单张 | **A4 横向**（297×210mm），处方纸居中留裁切边 |
| 拼版 2 / 4 张 | **A4 横向** |

> ⚠️ 打印对话框里的纸张方向请选「**横向**」。桌面版（exe）会自动指定纸张；若手动改过打印机设置导致不符，请在该对话框中调整。

### 导入数据：手动匹配数据项

自动识别列名不准时，可勾选「**手动匹配数据项**」，逐字段用下拉框指定来源列：

- **绿色下拉** = 自动匹配到的列
- **橙色下拉** = 你手动指定的列，标签显示「手动」
- 每行下方显示该列的**首行样例值**，便于核对是否选对
- 附「清空匹配」与「按名称补匹配」快捷按钮

手动指定的优先级高于自动匹配，留空表示不导入该字段。

### 界面

10 款配色（6 款浅色 + 4 款深色），一键切换并自动记忆。

### 数据安全

全部数据保存在浏览器本地存储（localStorage），不上传任何服务器，断网可用。

## 使用方法

### 直接打开

1. 下载 `处方打印助手.html` 与 `药品清单库.js`
2. 将两个文件放入**同一个文件夹**
3. 双击 `处方打印助手.html` 即可

> ⚠️ 两个文件必须位于同一目录，否则药品清单库无法加载（药品选择器会为空）。

### 打包为桌面程序（可选）

如需分发给不熟悉电脑的同事，可用 PyInstaller 打包成单文件 exe：

```bash
pyinstaller --onefile --noconsole \
  --add-data "处方打印助手.html;." \
  --add-data "药品清单库.js;." \
  -n 处方打印助手 启动器.py
```

启动器只需启动一个本机静态服务并打开默认浏览器，约 30 行 Python 代码即可实现。

## 目录结构

```
处方打印助手.html     主程序（界面 + 全部逻辑）
药品清单库.js        药品数据（4004 条）
build/                桌面版打包工程（Electron）
dist/                 打包产物：处方打印助手-1.0.0-win7portable.exe
```

## 浏览器要求

Chrome / Edge / Firefox 等现代浏览器。

「导入数据库文件」功能依赖 `DecompressionStream`（Chrome 103+ / Edge 103+ / Firefox 113+），用于在浏览器内直接解析 xlsx。

## 桌面版（exe）

`dist/` 下的 **便携版 exe** 无需安装，双击即用。

- **支持 Windows 7 / 8 / 10 / 11**（基于 Electron 22 / Chromium 108，官方最后支持 Win7 的版本）
- 单文件绿色版，数据存于 `%APPDATA%\处方打印助手`
- 打包命令：

```bash
cd build
npm install
npm run dist
```
