# 处方打印助手

面向药店与基层医疗机构的处方录入、识别与打印工具。纯前端单文件应用，**无需安装、无需联网，数据全部保存在本地**。

## 特性

### 智能识别

粘贴整张处方文字或收银小票，自动提取药品与患者信息。已适配多种真实排版：

- **标准处方文本** —— `美林混悬液/布洛芬混悬液 2g 100ML/瓶 10ML 必要时 口服 17.85 1瓶 17.85`
- **POS 收银小票** —— 自动跳过列名、操作项、批号、追溯码、收银员等噪音行
- **表格式明细** —— 识别「序号 / 商品信息 / 批号 / 零售价 / 实价 / 小计 / 销售员」等多列表格
- **品名规格对照** —— 识别「品名 + 规格」两列排版
- **患者信息** —— 姓名、性别、年龄、电话、会员号、地址支持多层兜底识别

### 药品清单库

内置 4000+ 条药品数据（通用名 / 品牌别名 / 规格 / 厂家 / 剂型 / 单位），支持搜索式快速录入，可按名称、别名、助记码、厂家模糊匹配。

### 处方要素

医院名称、患者姓名、性别、年龄、科别、就诊卡号、病历号、患者地址、处方医师、日期、发药药房、病情及诊断。

### 诊断管理

诊断条目支持**拖动排序**、**双击就地改名**、批量添加，独立持久化保存。

### 打印排版

固定 A5 处方纸（148 × 210 mm），版式紧凑、留白合理，适配常规处方笺打印。

### 界面

10 款配色（6 款浅色 + 4 款深色），一键切换并自动记忆。

### 数据安全

全部数据保存在浏览器本地存储（localStorage），不上传任何服务器，断网可用。

## 使用方法

### 直接打开

1. 下载 `处方打印助手.html` 与 `药品清单库.js`
2. 将两个文件放入**同一个文件夹**
3. 双击 `处方打印助手.html` 即可

> ⚠️ 两个文件必须位于同一目录，否则药品清单库无法加载（药品选择器会为空）。

### 打包为桌面程序（可选）

如需分发给不熟悉电脑的同事，可用 PyInstaller 打包成单文件 exe：

```bash
pyinstaller --onefile --noconsole \
  --add-data "处方打印助手.html;." \
  --add-data "药品清单库.js;." \
  -n 处方打印助手 启动器.py
```

启动器只需启动一个本机静态服务并打开默认浏览器，约 30 行 Python 代码即可实现。

## 目录结构

```
处方打印助手.html     主程序（界面 + 全部逻辑）
药品清单库.js        药品数据（4004 条）
```

## 浏览器要求

Chrome / Edge / Firefox 等现代浏览器。

「导入数据库文件」功能依赖 `DecompressionStream`（Chrome 103+ / Edge 103+ / Firefox 113+），用于在浏览器内直接解析 xlsx。
